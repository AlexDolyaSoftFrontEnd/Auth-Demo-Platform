# Auth Demo Platform

Демонстрационная платформа на React с использованием TypeScript, Redux Toolkit, Formik и Yup.

## Описание

Проект представляет собой **демо-приложение** для демонстрации подходов к разработке:

-  Валидация email с проверкой домена (настраивается)
-  Интеграция с Redux Toolkit для управления состоянием
-  Полная типизация TypeScript
-  Стилизация по методологии BEM
-  Адаптивный дизайн (mobile-first)
-  Готовая архитектура для масштабирования

> **Цель проекта**: Показать лучшие практики разработки React-приложений с аутентификацией.

## Технологии

- **React 18+** - UI библиотека
- **TypeScript** - типизация JavaScript
- **Redux Toolkit** - управление состоянием
- **Formik** - управление формами
- **Yup** - валидация схем
- **CSS3** - стилизация с BEM
- **React Redux** - интеграция Redux с React
